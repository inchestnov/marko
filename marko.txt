# 1. Описание проекта

## Название

Marko

---

## История названия

Marko происходит от слова **bookmark**.

Закладка — это отметка важного цифрового ресурса, к которому пользователь хочет вернуться.

Marko превращает обычные браузерные закладки в управляемую систему:

- с декларативным описанием;
- с шаблонами;
- с переиспользованием;
- с версионированием;
- с переносимостью между браузерами.

Marko — это инструмент управления структурой цифровых ресурсов.

---

# 2. Назначение проекта

Marko предназначен для создания, хранения и импорта структурированных закладок в браузер.

Основная проблема:

Обычные браузерные закладки плохо масштабируются:

- сложно поддерживать большое количество ссылок;
- невозможно использовать шаблоны;
- сложно создавать одинаковые структуры для разных проектов;
- невозможно удобно переносить структуру между браузерами;
- отсутствует возможность хранить закладки как код.

Marko решает эту проблему через подход Infrastructure as Code.

Пользователь описывает желаемую структуру закладок в YAML-файлах, после чего Marko импортирует её в браузер.

---

# 3. Основная идея

Marko работает по принципу:

> Bookmark infrastructure as code

Источник истины:

```

marko.yaml

```

Браузер является только конечным представлением структуры.

# 4. Требования к процессу разработки

## Обязательное требование: использование AI Sub-Agents

Разработка Marko должна выполняться с использованием агентной архитектуры.

Главный AI-агент, отвечающий за разработку проекта, НЕ должен выполнять все задачи последовательно самостоятельно.

Он должен создавать специализированных под-агентов для независимых областей работы.

---

## Главный агент (Lead Agent)

Ответственность:

- понимание требований;
- декомпозиция задачи;
- создание плана реализации;
- создание под-агентов;
- распределение задач;
- контроль результатов;
- интеграция компонентов;
- финальная проверка проекта.

Главный агент выступает как технический лидер проекта.

# 13. Templates

Template — переиспользуемый набор закладок.

Поддерживать:

- несколько bookmarks внутри одного template;
- вложенные templates;
- переменные;
- композицию.

---

# 14. Пример Kubernetes Template

```yaml
templates:

  kubernetes:

    folder:

      name: Kubernetes


    bookmarks:

      - name: Documentation

        url: https://kubernetes.io/docs/


      - name: GitHub

        url: https://github.com/kubernetes/kubernetes


      - name: Dashboard

        url: https://dashboard.company.com


      - name: Grafana

        url: https://grafana.company.com
````

Результат:

```
Kubernetes

├── Documentation

├── GitHub

├── Dashboard

└── Grafana
```
